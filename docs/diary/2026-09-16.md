# 2026-09-16 (Day 21) - OAuth Connections Screen Wiring

**Author:** Ishani

Wired the OAuth Connections screen (D21 spec) to real endpoints, replacing the mock data from D9. The frontend now fetches the list of connected providers directly from the backend, correctly rendering the active/expired/revoked states. I also wired the `Connect` and `Disconnect` buttons to trigger the respective OAuth flow endpoints, ensuring they act as local state toggles in the UI.

To fully satisfy the frontend's requirements to fetch connection status (since the backend was frozen), I added the necessary basic CRUD endpoints (`GET /oauth/connections` and `DELETE /oauth/{provider}`) to `oauth.py` using `supabase.table("oauth_connections").select()`. The widget tests have been updated with `MockClient` to intercept HTTP requests and verify state transitions locally without external `url_launcher` side effects.
