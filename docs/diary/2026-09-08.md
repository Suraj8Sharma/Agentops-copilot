# Day 14 — Real task submission

The Task Composer text path now submits exact user input to the authenticated `POST /tasks` endpoint with `input_type: text`, shows an explicit in-flight state, prevents duplicate submissions, preserves input on failure, and exposes retryable errors. A 401 is retried once through the existing auth/session refresh seam, while a successful task creation asks Home to refresh its real `GET /tasks` list; voice mode remains intentionally disabled until its Day 15/16 wiring is complete.
