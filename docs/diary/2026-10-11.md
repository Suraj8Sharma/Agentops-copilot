## Architectural & Free-Tier Decisions (Spec §7.2)

- Live LLM evaluations are executed locally before push with response caching (`.eval_cache.json`) and a 5-second inter-call delay to respect Groq free-tier rate limits (30 RPM / 8,000 TPM).
- CI runs offline checks only (`pytest` + `runner.py --check-results`), avoiding the need to expose Supabase service-role keys or burn API quota on PR builds.
- Added support for the 20+20 split run strategy in `backend/app/eval/runner.py` where results merge into `last_run.json`.
