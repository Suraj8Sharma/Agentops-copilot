# Day 20 — Banner copy rules

Defined and encoded the four notification banner copy rules: approval-needed copy is descriptive and never recommends a decision, task-completed copy is factual past tense, digest-ready copy states availability and period, and OAuth-expiring copy clearly names the provider and reconnect action without alarming language. Each rule now specifies permitted fields, required facts, forbidden claims, an 80-character budget, and a reference example for Jigyasu’s display work and Sanskriti’s D21 evaluation cases.
