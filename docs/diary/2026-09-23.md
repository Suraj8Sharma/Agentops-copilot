### Step 0 Findings & Discovered Issues (D28 Backlog)
During Step 0 static inspection of `google_token_refresh.py` and `api/routers/oauth.py`, two production gaps were verified and marked with `@pytest.mark.xfail(strict=True)` (documented in `docs/issues/d28-oauth-bugs.md`):
1. **`scope_mismatch` status ignored during token retrieval**: `get_valid_google_token` does not query or check the `status` column in `oauth_connections`, allowing non-active connections to proceed if unexpired. Test: `test_scope_mismatch_row_returns_none`.
2. **Missing provider validation on connection delete**: `DELETE /oauth/{provider}` does not validate `provider` against known providers, returning HTTP 200 on unknown providers rather than HTTP 404. Test: `test_disconnect_unknown_provider_returns_404`.

Both issues are deferred to D28 bug fixes without modifying production code on this test-only day.
